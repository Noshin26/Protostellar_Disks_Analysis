# Protostellar Disks Analysis

This repository contains Jupyter notebooks for analyzing protostellar disks using ALMA data. Notebooks include:

1. `Continuum_Imaging.ipynb` – imaging of continuum data.
2. `Continuum_Analysis.ipynb` – measurement of disk properties from continuum.
3. `Spectra_Analysis.ipynb` – cleaning and moment map generation for line data.
4. `generate-keplerian-masks.ipynb` – Keplerian mask generation for disk kinematics.
